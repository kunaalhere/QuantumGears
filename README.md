# QuantumGears
Quantum Gear GRUB Theme

A futuristic, schematic‑style GRUB boot theme that transforms your boot menu into a quantum mechanical blueprint – featuring interlocking gears, glowing particles, and a deep matte‑black chalkboard background.

Features

· 🎨 Stunning visual design – Blueprint grid, interlocking involute gears, motion arrows, and edge‑glowing particles.
· ⚙️ Interactive menu – 9‑slice gear‑tooth borders for selected items, with a pulsing “Quantum Core” status.
· ⏱️ Auto‑boot progress bar – Cyan glowing timer that counts down with GRUB’s timeout.
· 🔧 Fully reproducible assets – All images are generated by a Python script (Pillow) – no manual Photoshop needed.
· 📐 Configurable resolution – Generate backgrounds for any screen size (default 1920×1080).
· 🖋️ Custom fonts – Includes Orbitron (techno) and JetBrains Mono (monospace) – or fallback to GRUB’s built‑in fonts.

---

Requirements

· GRUB 2.06 or later (with gfxterm support).
· Python 3.6+ and Pillow (pip install Pillow) – for asset generation.
· (Optional) grub-mkfont (from grub-common package) – to convert TTF fonts to GRUB’s .pf2 format.

Installation

1. Clone or download the theme

```bash
git clone https://github.com/kunaalhere/QuantumGears.git
cd QuantumGears
```

2. Generate the assets

The theme relies on a set of raster images (background, menu slices, progress bar). Run the generator to create them:

```bash
# Install Python dependencies
pip install -r requirements.txt

# Generate assets (default: 1920x1080)
python3 scripts/generate_assets.py

# For a different resolution, e.g. 2560x1440:
python3 scripts/generate_assets.py --width 2560 --height 1440
```

The script will create:

· assets/background.png
· All 9‑slice images in assets/gear_slices/
· Progress bar slices in assets/

3. Convert fonts (optional)

If you have the TTF versions of the fonts (Orbitron‑Bold.ttf and JetBrainsMono‑Regular.ttf) placed in the fonts/ directory, you can convert them to GRUB’s .pf2 format:

```bash
chmod +x scripts/build_fonts.sh
./scripts/build_fonts.sh
```

Note: If you skip this step, GRUB will use its default font – the theme will still work, but the typography will differ.

4. Install the theme to your GRUB directory

Copy the entire theme folder to your GRUB themes location (commonly /boot/grub/themes/):

```bash
sudo mkdir -p /boot/grub/themes
sudo cp -r . /boot/grub/themes/quantum-gear-grub-theme
```

5. Configure GRUB to use the theme

Edit your grub.cfg (or a custom file in /etc/grub.d/) to load the theme. An example configuration is provided in grub.cfg.example:

```bash
set theme=(hd0,gpt1)/boot/grub/themes/quantum-gear-grub-theme/theme.txt
set timeout=30
set timeout_style=menu

# (Optional) pre‑load fonts
loadfont (hd0,gpt1)/boot/grub/themes/quantum-gear-grub-theme/fonts/Orbitron-Bold.pf2
loadfont (hd0,gpt1)/boot/grub/themes/quantum-gear-grub-theme/fonts/JetBrainsMono-Regular.pf2
```

Tip: Adjust the device path (e.g., hd0,gpt1) to match your system’s partition scheme.

6. Update GRUB

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

Reboot to see the new theme in action!

Customization

Changing colours

· In theme.txt: Modify the color blocks (e.g., chalk-white, cyber-cyan) to your preferred hex values.
· In scripts/generate_assets.py: Update the colour tuples at the top of the file (e.g., LINEWORK_COLOR, GLOW_COLOR) to match your new palette – then regenerate assets with the script.

Adjusting the gear layout

Edit the gears list inside the generate_background() function in generate_assets.py. Each gear is defined as (cx, cy, outer_radius, teeth, angle_offset). Add, remove, or reposition gears as you like, then run the generator again.

Changing the resolution

Pass --width and --height arguments to generate_assets.py to produce a background that matches your monitor’s native resolution.

Modifying menu item styling

· item_height, item_padding, and item_spacing in theme.txt control the menu item dimensions.
· To change the gear‑tooth border appearance, edit the slice generation logic in scripts/generate_assets.py (the generate_slices() function) and regenerate.

Troubleshooting

Problem Solution
Background does not show Check that assets/background.png exists and the path in theme.txt is correct (relative to the theme folder). Run python3 scripts/generate_assets.py again.
Menu items have no borders Ensure the 9‑slice images are present in assets/gear_slices/. Regenerate them if missing.
Fonts not loading Verify that .pf2 files exist in fonts/ and the loadfont commands in grub.cfg point to the correct paths. If absent, convert your TTF fonts or remove the loadfont lines to fall back to the default font.
Progress bar doesn’t animate GRUB’s progress_bar automatically reflects the timeout value. Ensure you have set timeout and timeout_style=menu in your grub.cfg.
Generator fails with “Pillow not found” Install Pillow: pip install Pillow. If you’re in a restricted environment, try python3 -m pip install --user Pillow.
Screen resolution mismatch Regenerate the background with your exact screen resolution using --width and --height.
GRUB shows “no suitable video mode” Ensure your GRUB is compiled with gfxterm support. Add set gfxmode=1920x1080 (or your resolution) before loading the theme in grub.cfg.

Advanced: Manual Asset Generation

If you prefer to tweak the assets without running the Python script, you can edit the resulting PNG files directly. However, any changes will be overwritten the next time you run the generator. It is recommended to modify the script and regenerate for consistency.
